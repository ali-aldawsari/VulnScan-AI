VulnScan AI

Overview

VulnScan AI is an automated vulnerability assessment tool developed as a cybersecurity graduation project.

The tool automates network scanning, service and version detection, vulnerability identification, report generation, and security notifications.

Key Features

- Automated network scanning using Nmap
- Service and version detection
- Vulnerability identification using CVE data
- Risk classification
- Automated PDF report generation
- Telegram security notifications
- Python-based implementation

Technologies & Tools

- Python
- Nmap
- Machine Learning
- CVE / NVD Data
- Telegram Bot API
- ReportLab
- Kali Linux
- VirtualBox

Workflow

1. Prepare the isolated lab environment.
2. Launch VulnScan AI.
3. Enter the target IP address.
4. Scan the target and identify services and vulnerabilities.
5. Generate a vulnerability assessment report.
6. Send security notifications through Telegram.

Lab Environment

The project was tested in an isolated VirtualBox environment using Kali Linux and target virtual machines.
